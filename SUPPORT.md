# Support ByTelli Development ❤️

ByTelli Developer Lab is an independent, phone-built Android development project.

If you find this project useful, you can help it grow in several ways:

- ⭐ **Star the repository** to help others discover it.
- 🐛 **Report bugs** with your Android version, device model, and steps to reproduce.
- 💡 **Suggest improvements** and new features using GitHub Issues.
- 🔧 **Contribute fixes** by opening a pull request. Improvements to Android compatibility, the editor, documentation, and build scripts are welcome.
- 📣 **Share the project** with Android and Termux developers.

## Need help?

Open a [GitHub Issue](https://github.com/black1771/ByTelli-Termux/issues/new) and describe the problem. Please do **not** post passwords, private keys, wallet recovery phrases, or personal information.

## Want to support development financially?
