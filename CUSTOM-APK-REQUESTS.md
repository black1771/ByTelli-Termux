# 📱 Custom Android APK Requests | Özel APK İstekleri

## 🇹🇷 Türkçe

İhtiyacınıza özel Android uygulamaları geliştirme taleplerini değerlendirebiliriz.

- Kişiye özel Android APK projeleri
- Dosya yöneticileri ve yardımcı araçlar
- Bluetooth ve cihaz entegrasyonları
- Otomasyon uygulamaları
- Mevcut açık kaynak projelere geliştirme desteği

**[📩 APK isteği gönder (GitHub Issues)](https://github.com/black1771/ByTelli-Termux/issues/new?template=custom-apk-request.yml)**

Her talep teknik uygulanabilirlik, kapsam ve geliştirme süresine göre değerlendirilir. İstek göndermek, projenin kabul edildiği veya ücretsiz/ücretli yapılacağı anlamına gelmez. Ücret ve teslimat koşulları varsa çalışmaya başlanmadan önce ayrıca kararlaştırılır.

## 🇬🇧 English

We welcome requests for custom Android APK development.

We can help with utility apps, file managers, Bluetooth integrations, automation tools, and improvements to open-source Android projects.

**[📩 Submit an APK request (GitHub Issues)](https://github.com/black1771/ByTelli-Termux/issues/new?template=custom-apk-request.yml)**

Requests are reviewed based on technical feasibility, scope, and development time. Submitting a request does not guarantee acceptance or imply that work is free or paid. Any pricing or delivery terms will be agreed separately before development.

**Privacy / Gizlilik:** Do not post passwords, private keys, API tokens, personal IDs or other sensitive information in public GitHub Issues.
