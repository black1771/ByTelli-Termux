# Contributing / Katkıda bulunma

Thanks for helping phone-only Android development! / Telefonda geliştirmeye katkı verdiğiniz için teşekkürler!

## How to help / Nasıl katkı verilir?
- Open an issue for a reproducible bug. / Tekrarlanabilen hata için issue açın.
- Submit a pull request for a documented fix or guide. / Belgelenmiş düzeltme veya rehber için PR gönderin.
- Include device, Android version, architecture, relevant tool versions, commands, expected result and actual result.
- Clearly mark untested suggestions as **untested / denenmedi**.
- Never post passwords, API keys, signing keystores, seed phrases, private tokens or unredacted personal logs.

## Pull request checklist / PR kontrol listesi
- [ ] Change is scoped and explained / Değişiklik açıklandı.
- [ ] Tested on a real device or marked untested / Gerçek cihazda denendi veya denenmedi olarak işaretlendi.
- [ ] Commands and versions are documented / Komutlar ve sürümler yazıldı.
- [ ] No secrets or proprietary binaries / Gizli bilgi veya izinsiz ikili dosya yok.

## Support / Destek
Use GitHub Issues for bugs, suggestions and troubleshooting. Community contributions are voluntary; no payment or reward is promised.
Hatalar, öneriler ve destek için GitHub Issues kullanın. Katkılar gönüllüdür; ücret veya ödül taahhüt edilmez.
